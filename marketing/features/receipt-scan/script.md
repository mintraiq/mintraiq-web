# Script — receipt-scan
Format: reel 1080×1920 · 28s · Pillar: Track (One thing Mintr does)

**One sentence.** For someone who gets to the end of a grocery shop with no idea
what made up the total, Mintr turns a photographed receipt into sorted line
items, so they can see the shape of the shop without typing anything.

No "and" in that sentence. It is one reel.

## Registers

**On-screen text carries the reel.** Most of this plays on mute — the voiceover
is a bonus and never the carrier. Every frame reads without sound.

**Nothing on screen exceeds six words.** The hook is two.

## What this reel does not say

No privacy claim, no security claim, no savings figure, no forecast, no "learns
from you". The reasoning is in `claims.md` — the short version is that the
receipt image does go to a third-party vision model for OCR, so any frame
implying the photo stays private would be false, and the narrow true claim about
local categorisation belongs on the categorisation entry instead.
